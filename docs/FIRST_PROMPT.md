Paste this into the first session in this repo.

---

This is our game, Zwei Grosse Bier Bar. Before doing anything:

1. Read `README.md`, `CLAUDE.md` and `docs/DESIGN.md`. Read the other `CLAUDE.md` files when you work in those folders.
2. Run `npm install` and `npm run ci`, and tell me if anything fails.
3. Run `npm run sim -- --nights 500` and keep the table as the balance baseline.
4. Start `npm run dev` and play a night yourself if you can drive a browser. Also open `/tools/sprite-lab/`.

Then give me a short summary: what you understood about the game, anything in the code or docs that looks wrong or inconsistent, and your suggestion for what to work on first from the to-do list in `docs/DESIGN.md`. Don't change any code until I've answered.
